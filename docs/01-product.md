# 01 产品规则 · 对译 Duiyi Android

> 状态：当前（2026-11-10）｜真源：本文件是产品行为与任务语义的唯一真源；实现现状见 [`09-current-state.md`](09-current-state.md)，已知取舍见 [`05-known-issues.md`](05-known-issues.md)。

产品定位：Android 手机原生、竖屏锁定的**多语言现场沟通 App**。面对面、同声传译、会议记录、任务历史是四个模块，不是四个 App；语义对齐 iOS 对译。

## 1. 产品承诺与原则

- **纯端侧**：听写、翻译、任务都留在本机；**绝不把云 STT / 云翻译当作离线不可用时的静默降级**。没有后端、没有账号、不上传音频。
- **简单**：每个模块主路径不超过「新任务 → 开始听 → 结束任务」；当面场景不要求用户理解延迟、VAD、模型等实现概念。
- **诚实**：设备/能力不支持就明说，并给替代路径（导出、换设备、系统设置）；**桩功能不假装可用**（当前总结、音频策略、语言能力探测、按需模型下载的边界见 09/05）。
- **可解释**：任何对用户可见的错误必须给出原因与下一步，不吞错误、不空转。
- 最低 **Android 14（API 34）**；仅 `arm64-v8a`；六种语言（中 / 英 / 日 / 韩 / 泰 / 越），实际可用性随设备能力与模型下载状态变化。

## 2. 四个模块

| 模块 | 谁在用 | 屏幕 | 核心产出 |
| --- | --- | --- | --- |
| 面对面 | 两人隔桌 | 上下对半，上屏容器 180° 倒字 | 双方各自看到对方语言的译文 |
| 同声传译 | 一个人听现场 | 单栏正字 | 实时译文；可选耳机读出 |
| 会议记录 | 一个人记一场会 | 单栏全文稿 | 单语完整文字稿（不翻译） |
| 任务历史 | 回看已结束的工作 | 列表 + 详情 | 回看、删除、导出分享 |

### 2.1 首页

- 三张模块卡 + 任务历史入口；有未结束任务时，列表置顶显示「未结束的任务」，点进对应模块继续。
- 顶部设置入口：我看的语言、字号、当前听写/翻译能力说明、模型与资源包入口、跳系统语音设置（部分机型）。
- 无底部 Tab；所有入口在首页滚动区。

### 2.2 面对面

- 手机平放、竖屏锁定，**不随重力翻转**；上半屏容器整体旋转 180°，不做逐字镜像。
- 双语字幕**以语种为路由键**（不做说话人分离）：谁说的语种决定译文写到哪一侧；不能确定时不乱翻，保持当前方向。
- **只翻译 final 句**（默认）；未开启增量翻译时，字幕先显示原文，译文在句子 final 后出现。
- 新任务后可按偏好自动开始听（默认开）；设置内可改双方语言、字号、自动开听、增量翻译开关、清屏、总结、对调双方语言。
- 两人抢话/插话时切换语种的识别是**尽力而为**，不承诺与 iOS 双路听写等价（见 05）。

### 2.3 同声传译

- 单栏正字；方向为「他说的语言 → 我听的语言」，两者必须不同。
- **新任务不自动开始听**；识别只跑源语言。
- 读出默认关。打开时要求已接有线/蓝牙耳机或听筒（`AudioSessionPolicy` 的耳机检测）；只有扬声器时禁止并提示「请戴上耳机再读出」。
- TTS 队列上限 2 句，按**增量后缀**朗读；无该语言朗读声时如实报错并关闭读出。

### 2.4 会议记录

- 单语全文稿：只记录一种语言，**不翻译、不朗读**。
- 进入会议模块即卸载翻译大模型，把内存/算力还给听写（重新进入翻译模块再按需加载）。
- 同一句修订合并进同一行；正文达到 2 万字符上限时提示「结束并新开一条」，不静默丢弃。
- 结束任务进入本条记录：全文 + 导出（总结为桩，见 09/05）。

### 2.5 任务历史

- 本地持久化（Room），按开始时间倒序、可按模块筛选；左滑删除需确认。
- 详情只读：回看字幕、导出 UTF-8 `.txt`（系统分享面板）；不提供编辑。
- 历史只包含**已结束**任务；未结束任务通过首页的「未结束任务」入口恢复。

## 3. 任务语义（所有模块一致）

| 动作 | 行为 |
| --- | --- |
| **新任务** | 若已有进行中任务，先确认结束并保存；清空现场字幕，记录开始时间、模块、语种 |
| **开始 / 暂停** | 只控制麦克风与听写；**暂停 ≠ 结束**，任务仍是进行中 |
| **结束任务** | 停听写 → 刷一次内存字幕到本地 → 写入历史；空任务（无任何非空源文）结束会删除且**不进历史** |
| **切模块 / 进后台 / 熄屏** | 进行中任务保持「进行中」，听写暂停；不做前台服务后台续听 |
| **杀进程** | 下次打开：未正常结束的任务标为「未结束」，可继续或结束保存 |
| **任务标题** | 自动生成：模块 + 语种/语言对 + 日期；会议记录可用首句前 16 字做副标题 |

- 设置里的「清屏」只清现场字幕，不影响已落盘内容；不提供「清任务但继续听」。

## 4. Android 设备分叉（产品必须提前说）

听写引擎按厂商分叉（实现入口 `SpeechEnginePolicy`）：

1. **荣耀 / 华为机型**：一律使用端侧 **sherpa-onnx SenseVoice**，**不尝试系统识别器**（默认引擎对第三方字幕经常不回结果）。需要先下载 SenseVoice 模型（约 240 MB）。
2. **其他厂商**：使用系统 `SpeechRecognizer`，优先端侧能力；识别服务按 Google → 其他 → 厂商排序；Google 应用缺麦克风权限时直接报错，并引导用户去系统设置授权。
3. 无 Google Play 服务的机型：听写可能不可用；翻译不依赖 GMS，仍可本机翻译。

**诚实边界**：非荣耀路径（Pixel / 三星等）只做了代码与 JVM 测试，**尚未真机验证**；不在 UI 上声称双引擎或离线六语全可用。设备能力文案由 `DeviceCapabilityProbe` / `DeviceLanguageCatalog` 给出，不可用语言在选语种处灰显并说明原因。

## 5. 语言、权限与数据

- 界面语种即「我看的语言」；现场语种（对方语言、同传源语言、会议语言）与界面语种分开设置。
- 权限只申请麦克风（听写）与网络（下载模型）；不申请账号、通讯录、后台录音；不保存音频。
- 文本只在 settled / 暂停 / 结束 / 进后台等节点写入本机；实时字幕以内存为准。
- 导出走系统分享面板；不内嵌第三方 SDK、不深链别的 App。

## 6. 明确不做（v1 / 本阶段）

- 不以云 STT、云翻译做静默降级（离线不可用就如实提示）。
- 不做账号体系、同步、后台前台服务听写、说话人分离。
- 不在会议记录里做实时同传朗读。
- 不做横屏、折叠屏双屏同时听写、平板分栏。
- 不把面对面与同声传译合并成一个 ViewModel；不为了「像 iOS」堆无意义对称层。
